# stingdev — نظرة عامة والقرارات المعتمدة

> منصة أعمال لمطور Full-Stack: موقع تسويقي + CMS + CRM Lite + مدونة + أعضاء + تعليقات + نشرة بريدية + لوحة تحكم + PWA.

## 1. الهوية

| البند | القيمة |
|---|---|
| اسم الكيان | `stingdev` |
| ملاحظة | الاسم والشعار وكل بيانات الهوية تُقرأ من `SiteSettings` في قاعدة البيانات، لا من الكود. تغييره لاحقًا لا يتطلب أي تعديل برمجي. |
| اللغة الافتراضية | العربية (`ar`) |
| اللغات المدعومة | `ar` (RTL) · `en` (LTR) |
| الجمهور | عملاء داخل السودان وخارجه (الخليج بشكل أساسي) |

## 2. القرارات التقنية النهائية

| المجال | القرار |
|---|---|
| Backend | Django 5.x + Django REST Framework |
| المصادقة | SimpleJWT — كوكيز HttpOnly للويب، Bearer للموبايل |
| قاعدة البيانات (تطوير) | SQLite |
| قاعدة البيانات (إنتاج) | PostgreSQL **أو** SQLite |
| المهام الخلفية | `django-q2` بوسيط ORM (لا Redis، لا Docker) |
| Frontend | Next.js 15 (App Router) + Tailwind CSS |
| الترجمة | `next-intl` للنصوص الثابتة · حقول `_ar/_en` للمحتوى الديناميكي |
| الأيقونات | `lucide-react` |
| الحركة | `framer-motion` (استيراد ديناميكي فقط) |
| طبقة النقل | `axios` |
| حالة الخادم في اللوحة | TanStack Query |
| حالة العميل | Context API — للمصادقة واللغة والثيم والإعدادات العامة فقط |
| لوحة التحكم | مخصصة بالكامل (لا Django Admin للاستخدام اليومي) |
| Docker | **غير مستخدم** — تشغيل محلي مباشر، ونشر تقليدي على VPS |

## 3. قيد ملزم: توافق قاعدة البيانات

بما أن SQLite خيار إنتاج محتمل، **يُمنع استخدام أي ميزة خاصة بمحرك واحد**.

**ممنوع:**
- `django.contrib.postgres` بالكامل (`ArrayField`, `HStoreField`, `SearchVector`, `TrigramSimilarity`, `GinIndex`).
- استعلامات SQL خام تعتمد على صياغة محرك بعينه.
- `select_for_update()` مع خيارات متقدمة.

**البدائل المعتمدة:**

| الحاجة | الحل المتوافق |
|---|---|
| قائمة قيم | `JSONField` (مدعوم في المحركين منذ Django 3.1) |
| علاقة متعددة | `ManyToManyField` عادي |
| بحث نصي | عمود `search_text` مطبَّع + `icontains` |
| ترتيب حسب الصلة | ترتيب يدوي بـ `Case/When` على مواضع التطابق |

### التطبيع العربي للبحث

دالة واحدة في `core/utils/text.py` تُستدعى عند حفظ أي كائن قابل للبحث، وتُخزَّن نتيجتها في `search_text`:

```
حذف التشكيل (U+064B..U+0652) · حذف التطويل (U+0640)
أ إ آ ٱ → ا   ·   ة → ه   ·   ى → ي   ·   ؤ → و   ·   ئ → ي
توحيد الأرقام الهندية إلى اللاتينية · تحويل لأحرف صغيرة · ضغط المسافات
```

نفس الدالة تُطبَّق على نص بحث المستخدم قبل الاستعلام. النتيجة: البحث عن «مشروع» يطابق «المشروع» و«مشروعٌ»، والبحث عن «الامارات» يطابق «الإمارات».

### احتياطات SQLite في الإنتاج

إذا اعتُمد SQLite إنتاجيًا، تُطبَّق هذه الإعدادات إلزاميًا:

- `PRAGMA journal_mode=WAL` — يسمح بقراءات متزامنة أثناء الكتابة.
- `PRAGMA synchronous=NORMAL` · `PRAGMA busy_timeout=5000`.
- عدد عمّال Gunicorn محدود (2–3) لتقليل تنازع الكتابة.
- عملية `django-q2` واحدة فقط بعامل واحد.
- نسخ احتياطي عبر `sqlite3 .backup` (لا نسخ الملف مباشرة أثناء التشغيل).

**متى ننتقل إلى PostgreSQL؟** عند تجاوز ~50 ألف زيارة شهريًا، أو عند بدء الحملات البريدية واسعة النطاق (كتابة مكثفة في `CampaignRecipient`). الانتقال لا يتطلب تغيير كود بفضل القيد أعلاه — تصدير واستيراد فقط.

## 4. أصول المحتوى الحقيقية

نقطة قوة المشروع أنه ينطلق بمحتوى حقيقي لا بمعلومات وهمية.

| المشروع | الجهة | القطاع | الحالة |
|---|---|---|---|
| منصة كلية الإمارات للعلوم والتكنولوجيا | مؤسسة جامعية | التعليم العالي | يعمل — `platform.eust.edu.sd` |
| موقع ونظام مدارس ومعاهد نمبر ون | مدارس ومعاهد | التعليم العام | يعمل — `numberoneschools.com` |
| 5+ مشاريع أخرى | — | متعدد | تُوثَّق في المرحلة 2 |

**أثر ذلك على البنية:**
- صفحات الحلول القطاعية الخاصة بـ **التعليم** تنطلق بمحتوى مدعوم بمشروعين منشورين — وهي أقوى صفحات الموقع.
- دراستا حالة كاملتان جاهزتان للكتابة.
- يجب حسم **إذن العميل** بالعرض لكل مشروع (`client_permission`)، ومع عدمه يُعرض المشروع مجهّلًا (`is_anonymized`) بلقطات ببيانات مموّهة.

## 5. مبادئ تُحكم كل قرار لاحق

1. **لا نص ديناميكي داخل الكود** — كل ما يظهر للزائر يأتي من قاعدة البيانات أو من ملفات الترجمة.
2. **الصفحات العامة Server Components افتراضيًا** — `"use client"` استثناء يُبرَّر.
3. **لا رموز في `localStorage`** — الكوكيز HttpOnly حصرًا في الويب.
4. **التحقق مزدوج** — كل قاعدة تحقق تُطبَّق في الواجهة وفي الـ API.
5. **كل صفحة لها أربع حالات** — تحميل، خطأ، فراغ، محتوى.
6. **القسم الفارغ يختفي تلقائيًا** — لا يعتمد على تذكّر إخفائه يدويًا.
7. **لا صفحة تُنشر بمحتوى رقيق** — النشر مشروط بحد أدنى من المحتوى.
8. **الخصائص المنطقية في CSS حصرًا** — `ms/me/ps/pe/start/end`، لا `left/right`.
