# ملحق واجهة المشروع (ui-profile)

> **المرجع الحاكم منذ 2026-10-23:** `docs/design/DESIGN.md` (Design Reference v2.2) مع `PROJECT_PROFILE.yaml` و`DECISIONS.md` في المجلد نفسه. ما هنا تفاصيل تنفيذ لا تخالفه. فحص التباين: `npm run check:contrast`. مستوى القراءة في الرئيسية (LANDING §2): `npm run check:copy`. التحميل بهيكل `ListSkeleton` لا مؤشر دوران (§4). نظام الخطوط والأرقام (D-0011): `npm run check:type`.

مبني على «وثيقة مراجعة وتطوير الكروت والواجهات». ما حُسم هنا لا يُعاد فتحه.

- **المشروع:** ستينج سيستم — الموقع العام ولوحة التحكم. العربية RTL أساسًا مع الإنجليزية في الموقع.
- **الأرقام:** لاتينية 0-9 في كل الواجهة. **الأوضاع:** فاتح وداكن. **الأحجام:** الموقع 390 و1440، اللوحة 1440.
- **المكتبة:** Next.js + Tailwind؛ الرموز في `tailwind.config.ts` و`globals.css`؛ المكوّنات المشتركة `components/ui/*` و`components/content/cards.tsx`.
- **الهوية:** الموقع هادئ وموثوق يقدّم الأعمال الحقيقية؛ اللوحة تشغيلية كثيفة المعلومات.

## الاتجاه المختار (2026-10-15)
- **الموقع العام: كروت المعاينة.** المشروع يُعرض بصورته الحقيقية أولًا. بطاقة بلا غلاف نصية بحتة، بلا شريط ملوّن.
  أيقونة القطاع علامة مسح بلا مربع مصبوغ.
- **اللوحة: الهادئ الدقيق.** المؤشرات الرقمية خلايا في شريط واحد مفصول بخط (`GRID` في `dashboard/(workspace)/page.tsx`)،
  لا بطاقة ولا أيقونة لكل رقم. لا ظل ولا رفع عند التحويم على خلية؛ تغيّر الخلفية فقط.

## الأنماط الممنوعة وكيف تُفحص
`npm run lint:ui` (من `frontend`): شريط ملوّن على حافة بطاقة، أيقونة في مربع/دائرة مصبوغة، حركة مستمرة على عنصر ساكن.
ينتهي بالفشل عند مخالفة، وبنجاح صامت عند الخلو. الاستثناءات الوظيفية موثقة في `frontend/scripts/ui-allow.txt`
(مسار | جزء سطر | سبب): خط التبويب النشط، خط الاقتباس، تمييز رد الفريق، رقم الخطوة، هياكل التحميل.
الفحص لا يغني عن المراجعة البصرية.
