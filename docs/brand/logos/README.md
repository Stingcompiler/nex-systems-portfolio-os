# شعارات ستينج سيستم

افتح `logos.html` لعرض كل الشعارات في صفحة واحدة (تعمل دون اتصال).

- `adopted/` — الشعار المعتمد «السين البيانية»: العلامة (SVG وPNG 512)، والشعار مع الاسم بالعربية والإنجليزية.
- `alternatives/` — المقترحات التي لم تُعتمد، والشعار السابق.

أيقونات الموقع وصور المشاركة تُولَّد من `frontend/scripts/generate-icons.py` ثم `generate-og.py`.
